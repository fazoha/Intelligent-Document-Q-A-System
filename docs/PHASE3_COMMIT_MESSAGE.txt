feat: Implement Phase 3 - Confidence Scoring, Extractive Fallback & Evaluation

Phase 3 enhances the Intelligent Document Q&A System with confidence scoring,
extractive fallback for low-confidence answers, and a comprehensive evaluation
harness for systematic benchmarking.

## Core Features Added

### Confidence Scoring System
- Implemented ConfidenceScorer using ROUGE-L (Longest Common Subsequence)
- Validates that generated answers are supported by cited chunks
- Token overlap calculation as secondary signal
- Confidence levels: high (≥0.7), medium (0.4-0.7), low (<0.4)
- Visual indicators in frontend (color-coded percentages)

### Extractive QA Fallback
- Added ExtractiveQAService using DistilBERT (distilbert-base-uncased-distilled-squad)
- Triggers automatically when generative confidence < threshold (default: 0.4)
- Extracts direct spans from source documents
- Provides character positions for potential highlighting
- Lazy model loading to avoid startup delay

### Evaluation Harness
- Implemented standard QA metrics: Exact Match, F1 Score, Recall@K, nDCG, MRR
- Benchmark framework with dataset loading and comparison
- Sample dataset with 10 hand-crafted QA examples
- Ablation study support for systematic testing
- CLI evaluation script (evaluate_phase3.py)

## Performance Impact

- Confidence scoring: +10-30ms per query
- Extractive fallback (when triggered): +100-200ms
- DistilBERT model: ~260MB (downloaded on first use)
- Total query time: ~2-3s end-to-end

## Architecture

```
Query → Query Planner → Hybrid Retrieval → Reranking
                                            ↓
                                    GPT-5-mini Answer
                                            ↓
                              Confidence Scoring (ROUGE-L)
                                            ↓
                         High Confidence → Return Answer
                         Low Confidence  → Extractive Fallback
                                            ↓
                                    Return Best Answer
```
