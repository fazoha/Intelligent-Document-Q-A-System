feat: Implement Phase 2 - Hybrid NLP Retrieval & Advanced Query Processing

Phase 2 enhances the Intelligent Document Q&A System with advanced NLP
components, implementing hybrid retrieval, neural reranking, and multi-hop
query planning while maintaining a pure Python NLP approach.

## Core Features Added

### Hybrid Retrieval System
- Implemented HybridRetriever combining dense embeddings (OpenAI) with YAKE
  keyword extraction for improved retrieval accuracy
- Weighted score fusion (Dense: 0.7, Keywords: 0.3) for optimal results
- Removed BM25/Elasticsearch dependency for simplified pure NLP architecture

### Neural Reranking
- Added CrossEncoderReranker using ms-marco-MiniLM-L-6-v2 model
- Reranks top 20 candidates to final top 5 for precision improvement
- Significantly improves answer quality through semantic relevance scoring

### Query Planning & Multi-hop Reasoning
- Implemented QueryPlanner with spaCy dependency parsing
- Detects multi-hop queries and decomposes into sub-queries
- Enables complex questions requiring information from multiple document sections

### Enhanced Chunking
- Improved ChunkBuilder with better table extraction and section hierarchy
- Preserves layout metadata for accurate citations
- Enhanced handling of structured content (tables, headings, lists)

## Technical Changes

### New Services
- services/hybrid_retriever.py: Orchestrates multi-strategy retrieval
- services/keyword_service.py: YAKE-based unsupervised keyword extraction
- services/reranker_service.py: Cross-encoder neural reranking
- services/query_planner.py: Multi-hop query analysis with spaCy

### Configuration Updates
- Updated config.py with Phase 2 parameters (weights, reranking, query planning)
- Adjusted retrieval weights for 2-component hybrid (removed BM25_WEIGHT)
- Added spaCy model configuration and multi-hop enable flag

### API Enhancements
- Updated query route to use HybridRetriever and QueryPlanner
- Enhanced document routes with improved chunking pipeline
- Maintained backward compatibility with existing API contracts

### Infrastructure
- Added setup_phase2.py for automated Phase 2 verification

  spacy, torch, unstructured)
- Removed elasticsearch dependency (pure Python NLP approach)
